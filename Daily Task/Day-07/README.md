# Day 07 - Collections Framework

## Topics Covered
- `List`, `Set`, `Queue`
- `ArrayList` vs `LinkedList`
- `LinkedHashSet` (no duplicates)
- `ArrayDeque` (FIFO queue)
- `PriorityQueue` (priority sorting)
- `Iterator.remove()` (safe removal)

## Hands-on Task: Library Waitlist
Created `LibraryWaitlist.java`:
- `ArrayList` for book catalogue
- `LinkedHashSet` for unique book titles
- `ArrayDeque` for standard waitlist (FIFO)
- `PriorityQueue` for serving Faculty before Students
- `Iterator.remove()` for removing overdue items without crashing
- Timing comparison between `ArrayList` and `LinkedList`

## How to Run
```bash
javac LibraryWaitlist.java
java LibraryWaitlist
```
