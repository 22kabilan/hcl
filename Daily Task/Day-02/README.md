## Daily Hands-on Task

Implemented a **Monthly Usage Analyser** using Java.

The program demonstrates:

- A 12-month `int[]` array
- Constants using `final`
- Total monthly usage
- Average usage using type casting
- Maximum and minimum usage
- Grade calculation using the ternary operator
- `long` to prevent integer overflow
- A 2-D array for usage data of three houses
