# Day 04 - OOP Concepts + IDE & Debugging

## Topics Covered
- Classes, Objects, Fields, Methods
- Encapsulation (private variables, getters)
- Constructor overloading and chaining (`this()`)
- Static counter (`static int count`)
- `equals()` and `hashCode()`
- Debugging with Breakpoints and Watches

## Hands-on Task: Bank Account
Created `BankAccount.java`:
- Private fields: `accNo`, `name`, `balance`
- Static account counter
- 3 chained constructors using `this()`
- Validated `deposit()` and `withdraw()`
- Overridden `equals()` and `hashCode()`

## How to Run
```bash
javac BankAccount.java
java BankAccount
```
