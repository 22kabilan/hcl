# Day 03 - Control Flow + Maven

## Topics Covered
- `if-else` and `switch`
- `while`, `do-while`, and enhanced `for`
- `break` and `continue`
- Maven basic structure and profiles

## Hands-on Task: ATM Simulator
Created `AtmSimulator.java`:
- 3 PIN attempts with `break`
- `do-while` menu with `switch`
- Balance check, deposit, and withdraw
- Mini-statement using enhanced `for` loop
- `continue` when input choice is invalid

## How to Run
```bash
javac AtmSimulator.java
java AtmSimulator
```
